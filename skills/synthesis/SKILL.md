# Synthesis — Финальный синтез

Собирает результаты всех раундов дебатов в три выходных документа: отчёт, карту расхождений и лог допущений.

## Вход

Все файлы из `output/`:
- `round1-user-advocate.json`
- `round1-biz-advocate.json`
- `round2-critic.json`
- `human-direction.md` (если есть)
- `round3-user-advocate.json` (если есть)
- `round3-biz-advocate.json` (если есть)

## Выход

### 1. `output/RESEARCH_REPORT.md`

```markdown
# Отчёт: [тема из context.md]

## Резюме
Одна ключевая находка + уровень уверенности + главное расхождение.

## Консенсусные выводы
Findings, которые:
- Оба агента подтвердили И Критик не смог атаковать (strongest_findings)
- Или агент защитил при критике (defend в раунде 3)
Для каждого: утверждение, evidence, уверенность.

## Скорректированные выводы
Findings, которые были пересмотрены (revise/refine) после критики.
Для каждого: исходное утверждение → обновлённое, что изменилось и почему.

## Опровергнутые выводы
Findings, которые Критик атаковал с severity=critical
И агент не защитил (или согласился пересмотреть).
Для каждого: что утверждалось, почему это неверно, альтернативная интерпретация.

## Открытые вопросы
- Вопросы от агентов, на которые данные не ответили
- Blind spots от Критика
- Направления для дополнительного исследования

## Рекомендации
Приоритизированный список действий.
Для каждого: что делать, на каком выводе основано, уровень уверенности, ожидаемый импакт.

## Методология
Описание процесса: сколько раундов, какие модели, какие решения принял исследователь и почему.
```

### 2. `output/DIVERGENCE_MAP.md`

```markdown
# Карта расхождений

Точки, где Адвокат пользователя и Адвокат бизнеса пришли к РАЗНЫМ выводам
на основе тех же данных. Это зоны для дополнительного исследования.

## Расхождение 1: [тема]
- **Адвокат пользователя** (UA-N): [утверждение]
- **Адвокат бизнеса** (BA-N): [противоположное утверждение]
- **Критик**: [что сказал об этом расхождении]
- **Статус**: нерешено | решено человеком
- **Почему важно**: [импакт на решения]
- **Что нужно для разрешения**: [конкретные данные или эксперименты]
```

### 3. `output/ASSUMPTIONS_LOG.md`

```markdown
# Лог допущений

Все предположения, сделанные агентами без прямых данных.
Каждое допущение — потенциальный риск для выводов.

| ID | Агент | Допущение | Импакт если неверно | Статус |
|----|-------|-----------|---------------------|--------|
| UA-A1 | User Advocate | ... | ... | не проверено |
| BA-A1 | Biz Advocate | ... | ... | не проверено |
```

## Правила синтеза

1. **Не добавляй своих выводов** — только систематизируй то, что уже есть
2. **Сохраняй ID** — каждый вывод в отчёте должен ссылаться на исходный ID (UA-1, BA-2, CR-3)
3. **Фиксируй решения человека** — если исследователь выбрал одну интерпретацию, запиши его обоснование
4. **Честно размечай уверенность** — consensus findings = high, corrected = medium, unresolved = low
5. **Рекомендации только из выводов** — никаких рекомендаций, не подкреплённых findings

## Когда запускать

- После всех раундов (автоматически в конце пайплайна)
- Или вручную: `/synthesis` — даже если был только раунд 1 + критика (без раунда 3)
